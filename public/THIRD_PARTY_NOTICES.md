## Cue Foundations — Phantom Infinite Gallery

The channel gallery in `src/ui/phantom-infinite-gallery.tsx` is adapted from the public source published at:

https://kit.cuedesign.space/components/phantom-infinite-gallery

Upstream repository: https://github.com/aloksivastava1025-prog/cue-foundations

The supplied shadcn registry endpoint returned HTTP 500 (`Source missing`) when integrated, so the source was retrieved from the component's public manual-install page. Raeen's adaptation uses community channels and original local SVG artwork, container-relative geometry, bounded visible tiles, an animation loop that stops when idle/hidden, keyboard controls, reduced-motion support, and accessible focus previews. No upstream Pinterest images are included.
